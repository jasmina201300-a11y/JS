Основы JavaScript: Переменные и Типы данных

Любая программа на JavaScript хранит информацию в переменных (const, let, var), а сама информация делится на типы данных, главные из которых — Number и String.

01. Переменные: const, let и var

Переменная — это «коробка» с именем, в которую программа кладёт данные (число, строку и т. д.), чтобы использовать их позже. В JS есть три способа создать переменную:

const Используй по умолчанию

Сокращение от constant (константа). Создаёт переменную, значение которой нельзя перезаписать.

  • Обязательно нужно сразу задать значение при создании.
  • Защищает код от случайных изменений важных данных.
  • Работает только внутри своего блока { ... }.
const birthYear = 2013;
birthYear = 2014; // ❌ Ошибка! Нельзя менять
let Для меняющихся данных

Современный способ создать переменную, значение которой можно менять по ходу работы программы.

  • Подходит для счётчиков, очков в игре, возраста.
  • Нельзя объявить две переменные с одинаковым именем в одном блоке.
  • Видна только внутри фигурных скобок { ... }, где создана.
let score = 0;
score = 10; // ✅ Работает! Теперь score = 10
var Устаревший способ

Старый способ создания переменных из ранних версий JS (до 2015 года). Сейчас в новых проектах не используется.

  • Игнорирует блоки if и циклы — «протекает» наружу.
  • Разрешает случайно создать переменную с тем же именем заново.
  • Всплывает вверх кода (hoisting), из-за чего вызывает путаницу.
var name = "Али";
var name = "Омар"; // ⚠️ Перезаписал без ошибки
Характеристика const let var
Можно ли изменить значение? Нет Да Да
Можно ли объявить заново с тем же именем? Нет (ошибка) Нет (ошибка) Да (опасно)
Область видимости Блочная { } Блочная { } Функциональная (устарело)
Когда применять? Всегда, если значение не меняется Когда значение будет меняться Никогда (только в старом коде)
Главное правило современных разработчиков: всегда пиши const. Если позже поймёшь, что значение переменной должно меняться — поменяй const на let. Про var нужно знать только для чтения чужого старого кода.

02. Тип данных Number (Число)

В JavaScript нет разделения на целые и дробные числа — для всех математических значений используется единый тип Number.

Number typeof 42 === "number"

Числа пишутся без кавычек. С ними можно выполнять любые арифметические операции: сложение, вычитание, умножение, деление и возведение в степень.

const age = 13; // целое число
const price = 99.95; // дробное (через точку)
let sum = 10 + 5 * 2; // результат: 20
Специальные числа Infinity & NaN

Помимо обычных цифр, к типу Number относятся три особых значения:

  • Infinity — математическая бесконечность (например, при делении 1 / 0).
  • -Infinity — отрицательная бесконечность.
  • NaN (Not a Number) — вычислительная ошибка, например при попытке умножить текст на число: "привет" * 2.

03. Тип данных String (Строка)

Строка — это любой текст: от одной буквы до целой книги. В JavaScript любая строка обязательно заключается в кавычки.

String typeof "Hi" === "string"

В JS существуют три вида кавычек. Двойные и одинарные работают одинаково, а обратные позволяют встраивать переменные прямо внутрь текста.

const str1 = "Двойные кавычки";
const str2 = 'Одинарные кавычки';
const name = "Жасмина";
const hello = `Привет, ${name}!`;
Особенности строк Склейка и длина

Строки нельзя вычитать или делить, но их можно соединять (это называется конкатенация) и узнавать их длину:

  • Знак + склеивает строки: "Java" + "Script" даст "JavaScript".
  • Свойство .length считает количество символов (включая пробелы).
  • Цифры в кавычках "123" — это уже строка, а не число.

Главное отличие: 5 против "5"

Новички часто путают число и строку с цифрой внутри. Посмотри, насколько по-разному они ведут себя в коде:

Выражение Результат Почему так происходит
5 + 5 10 (Number) Оба значения — числа, происходит обычное сложение.
"5" + "5" "55" (String) Оба значения — строки, JS просто склеивает два текста.
"5" + 5 "55" (String) Если хотя бы один элемент строка, знак + превращает всё в строку.
"10" - 4 6 (Number) Минус работает только с числами, поэтому JS сам превращает "10" в число 10.

Остальные типы данных в JS

Всего в JavaScript 8 типов данных. Кроме Number и String, в языке есть ещё 6:

Boolean Логический тип: только true (истина) или false (ложь).
Undefined Значение не присвоено (переменная создана, но пуста).
Null Специальное значение «ничего» или «пустота».
BigInt Для работы с огромными целыми числами.
Symbol Для создания уникальных идентификаторов.
Object Сложные структуры: коллекции данных, массивы, функции.
